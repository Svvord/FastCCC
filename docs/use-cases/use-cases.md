# Use cases

Three questions FastCCC is built to answer, each with the command that answers it.

- [Compare with healthy tissue]({{ site.baseurl }}/use-cases/compare-cell-cell-communication-with-healthy-tissue.html): which communications a disease sample gained, lost or kept, against a healthy tissue panel, a control group or a reference you build with one command.
- [A million cells or more]({{ site.baseurl }}/use-cases/cell-cell-communication-million-cells.html): the CellPhoneDB score with an analytic p-value, for datasets on which permutation takes too long.
- [FastCCC compared with other tools]({{ site.baseurl }}/use-cases/fastccc-vs-cellphonedb-cellchat-liana.html): side by side with CellPhoneDB, CellChat, LIANA+ and MultiNicheNet, and when to choose FastCCC.
